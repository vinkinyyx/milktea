## 3. 你现在需要做什么

### 第一步：准备Creator运行环境（当前阻塞项）

1. 从 [Cocos官方下载页](https://www.cocos.com/creator-download) 安装Dashboard及Creator **3.8.8**。本工程开发类型声明已固定为3.8.8，建议先用相同补丁；如果采用其他3.8 LTS补丁，需用对应引擎声明重新检查。类型声明不是引擎本体。
2. 能正常启动编辑器，并保留实际安装路径与版本信息。用Dashboard的Add Project选择 `D:/Workspace/TapTap/奶茶挤挤/client`，不要选仓库父目录。
3. 等待资源导入完成，保留现有.meta，让编辑器为新增脚本和PNG生成实际.meta。在项目设置的功能裁剪中选择2D Box2D或Box2D WASM，记录实际后端；Builtin不能用于本项目刚体。
4. 打开 `assets/scenes/Boot.scene`，选择当前场景预览。若PhysicsLab场景未被自动纳入预览/构建场景列表，将Boot和PhysicsLab都加入，Boot作为启动场景。只有实际导入后才能确认这条启动路径。

**你最少只需完成安装并能启动Creator，提供实际版本/路径。** 后续导入错误定位、物理验收、证据整理与构建属于开发工作，可以继续交给开发负责人执行。以下是完整验收方法，便于你检查结果。

### 第二步：复跑代码与素材检查

从 `client/` 执行：

```powershell
npm ci
npm run typecheck
npm run verify:art
```

`typecheck` 检查全部客户端脚本；`verify:art` 检查配置/时钟/坐标纯逻辑、120步自动暂停边界、图片实际文件哈希/尺寸、九切/锚点和图片选档。默认证据输出到 `evidence/progress-2026-10-27-art-binding/`。这些检查不替代Creator预览、物理或平台构建。

### 第三步：完成P1-A实际验收

| 操作 | 应核对和留存的实际结果 |
| --- | --- |
| `1` 单圆自由落体 | 控制台在30/60tick输出真实位置、速度和位移。解析解0.5秒122.5DU、1秒490DU；记录实测离散误差。60Hz半隐式积分参照为126.583/498.167DU，不能将参照值填成实测值 |
