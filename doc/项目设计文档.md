## 2026-11-06 第二整改轮（代码完成，验证未执行）

| 领域 | 设计变更 |
|---|---|
| 资源预算 | 前台时间按 hide/show 分段记账；后台不计、真实前台超时必生效；scope 令牌化，旧批次不得拆除新批次 |
| 错误恢复 | 普通渲染抛错仍提供独立 overlay 出口；返回菜单清 overlay/pointer/按钮并可重新开局 |
| 设置面板 | 设置使用独立 `SETTINGS_UI` 资源 scope，首屏仍按需加载 `ui_*` |
| 奖励宿主交接 | 交接后不残留 SHOWING/SETTLING；同 run 已提交 receipt 免费恢复，持久 used=1 优先于内存 used=0 |
| 启动诊断 | `BOOT_CONFIG` 及读/校验/物理/GameRoot 失败阶段分离，附错误摘要与前6帧堆栈 |
| 广告门槛 | 60 秒前台保护仅约束首局完成前；无限模式以“完成一局”映射平台“1个关卡”，不保留对老玩家的永久隐形阻断 |
| 交接遗留记录 | 交接后旧 `pendingAttempt` 立即解除阻断并异步清理，新宿主不会被 `PENDING_ATTEMPT` 永久卡住 |
