# 项目设计导航

当前产品为透明窄杯接住自动落下的小料，同级相遇合成；按住杯子左右移动，保留晃杯与无限重玩。Cocos Creator3.8.8发布Tap小游戏，经典款优先；不是旧版单指选落点松手投放或抖音首发规划。

每局两次免费晃杯，额外晃杯广告与洒出广告复活分别记账、展示互斥。复活完整观看后同局同分继续，一局最多一次成功复活，无未经授权的每日上限；失败/取消保留选择，技术恢复免费。正式广告无真实ID时继续关闭。
