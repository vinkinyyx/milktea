## 目录
- `01_已生成原创设计参考`：上一轮已生成的Logo、猫咪、3级小料、带奶盖奶茶、背景、按钮样式、3张界面效果图，以及两份总览拼版。它们是**整张原画/概念图**，不具备独立透明运行图层。
- `02_九级小料_矢量试制`：九级均按原asset_id制作新的独立矢量SVG，导出1024/512/256/128 RGBA PNG及96缩略；左上柔光，近圆物理边界。它们是**矢量技术试制版**，并非将原3张高精度原画无损转成分层文件，细腻程度和照片式高光尚需最终锁版。
- `03_经典杯七层_矢量试制`：7个750×1000 RGBA PNG和相同画布SVG，透明、不可自动裁切，基于参考CupGeometry构建；这款是游戏用开口杯，**不同于**带吸管/奶盖/现成珍珠的宣传插画。
- `04_核心按钮_矢量试制`：主按钮、次按钮、图标按钮各normal/pressed/disabled/selected，共12份SVG+PNG，**不烘焙动态文字**。
- `05_预览与质检`：九级小料并排图、杯体七层叠加预览。
- `06_文档与清单`：本README、manifest.json、资产状态表、自动技术核验和下一步QA清单。

## 工程引用
- 小料在运行时按物理直径36/48/64/84/110/140/178/224/280 DU缩放（统一母版轮廓约900px），其纹理画布不得直接当作碰撞直径。
- 杯体美术复核物理参考：杯内顶端x=115/635，底端x=195/555；图中顶端y≈140、底端y≈940；**最终以项目真实CupGeometry导线测试为准**。
- 小料要夹在杯后层与前层之间。请在Cocos中测试透明排序、BGM+SFX及真实游戏下落、堆叠、晃杯。
- 旧三张生成小料保留为美术高精度标杆；新的九级矢量组先作为规则一致性和运行试制稿。不可把整张概念图或分镜拼版当作游戏截图交平台审核。
