# 《奶茶挤挤》V2.0 第五批｜挑战、广告与平台适配

## 范围
按照原始213资产表中P4-A(11项)、P4-C(2项)、P4-D(4项)执行，共**17个asset_id**。
其中**12项静态图片**（7功能图标+挑战卡+2挑战分享背景+2渠道封面/图标候选）；**2项引擎运行时组件**、**3项平台原生资源**仅提供接口约束和说明，不能冒充AI绘制成品。

## 文件结构
- `01_P4A_挑战图标与卡片`：6个挑战相关新绘源/图标和卡片；7个图标中的外链与广告位于对应阶段文件夹
- `02_P4A_每日与好友分享卡`：双分享卡：SVG矢量布局（嵌入V2奶茶店栅格背景）+ 750×1000 PNG + layout.json
- `03_P4C_自愿广告`：自愿播放图标SVG/PNG；不包含伪造的平台广告标识
- `04_P4D_平台适配`：原创“外链”图标，基于既有母版的TapTap封面/微信图标候选
- `05_页面视觉稿_非实机`：每日、好友、广告、分享共5幅概念稿。**不能用于要求真实游戏截图的正式提审**
- `08_引擎与平台接口说明`：程序与平台管理的5个资产ID使用约束

## 确认范围，不自动新增功能
只制作已经确认的每日同题/好友挑战/自愿广告/平台发行所需视觉资产；概念参考图中出现的金币、钻石、活动兑换、商城、礼包、体力等并非本批新增需求，也没有提供对应运行资产。

## 使用说明
所有按钮文字、当前分数、挑战日期、120投剩余、好友头像、昵称、真实挑战入口码均必须在Cocos运行时注入。图标仅为候选新绘源；状态以及触摸热区由程序实现。挑战面板按 `nine_slice=24,24,24,24` 处理。微信与TapTap上传规格应在正式提交时核对实际开发者后台，本包不能替代平台实时要求。

## 版权与测试
V2元素来自本项目此前制作的图像与本批原创矢量；背景栅格图嵌入SVG，**不能把整张分享卡称为100%纯矢量**。没有完成真机Cocos集成、可用性、平台授权与广告SDK回归，因此保持工程试制状态。
