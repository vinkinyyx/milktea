# 《奶茶挤挤》V2.0 第六批：发行与宣传素材包

## 定位
用于微信小游戏、抖音小游戏、TapTap 小游戏/商店的美术升级与发行准备。素材来源为本次新生成的V2风格主视觉和图标及前五批已有UI参考资产；**属于视觉候选设计而非经平台审核通过的文件**。

## 游戏短简介（候选）
把小料投入奶茶杯，同级碰撞就能合成升级。合理安排空间，挑战更高分数！

## 详细介绍（候选，以最终实机功能核验为准）
《奶茶挤挤》是一款以奶茶小料为主题的竖屏休闲益智小游戏。玩家调整投放位置，将西米、红豆、珍珠、椰果等小料投入杯中；相同等级的小料接触后合成为更高级的小料。随着杯中小料逐渐增加，需要利用空间、观察落点和碰撞关系，尝试获得更高成绩。游戏提供经典奶茶杯及多种不同杯型的视觉主题，并通过清晰的得分、危险提示和结算反馈帮助玩家了解结果。玩家可以在碎片时间进行挑战，享受轻松的合成玩法。是否实际开放某种杯型、排行榜、好友挑战和广告功能，以已上线的游戏版本为准。

## 图片使用指南
- 01 应用图标：游戏图标使用**直角方图**，不可自带圆角、官方标识、平台水印，上传前按后台校验。
- 02 宣传主视觉：TapTap 小游戏横版1920×1080、方形1440×1440 **仅有游戏名**，无其他宣传文字，输出JPG均控制在2MB内。无字图供另行适配。
- 03 启动/分享：启动底图无加载百分比、分数与按钮；成绩分享卡所有真实成绩/账号信息/平台入口码由程序动态叠加，不得伪造。
- 04 实机截图：4套仅为**透明边框模板**，不含任何游戏内容。请用Cocos真机运行画面生成真实截图，不要将概念稿上传提审。
- 05 宣传分镜：5帧为内部视频策划参考，其中的游戏界面是概念图，**不能当作TapTap要求的实机录屏**。

## 下一步交给Codex
1. Cocos Creator真机运行，截取投放、连续合成、杯型/关卡和图鉴/榜单真实画面。
2. 输出一致竖向≥720×1280，截图至少3张，尺寸、大小按目标渠道的实时后台规则复核。
3. 录制一段真实游戏运行操作视频（TapTap小游戏要求实机录屏，不可用美术分镜代替）。

## 现阶段的不足
- V2主视觉包含装饰化的奶盖、吸管和飞溅小料，表达的是营销概念，不代表当前经典杯的实际物理玩法。不得由此反推游戏存在流体模拟或隐藏的物理机制。
- 本次背景的角色与先前各批角色可能存在局部造型差异，需要在后续统一美术终审确认是否用同一个角色母版重构。
- 没有导入真实 Cocos 项目，无法宣称运行时截图与平台审核已完成。
