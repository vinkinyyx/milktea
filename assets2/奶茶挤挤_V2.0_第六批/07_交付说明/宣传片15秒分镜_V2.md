# 15秒宣传片分镜方案（策划，不是成片）

| 时间 | 内容 | 制作方式/素材 |
|---|---|---|
| 0–3秒 | 奶茶店出场，品牌出现 | 01 开场品牌画面；真实成片可用动态转场 |
| 3–6秒 | 小料下落进杯，玩家选定落点 | 请替换为 Cocos 实录，而不是静态镜头 |
| 6–9秒 | 两个同级小料相撞合成，分数上升 | 真实游戏实录并与逻辑一致 |
| 9–12秒 | 五款杯型主题展示，已开放内容为准 | 已实现的杯型选择录屏 |
| 12–15秒 | 奶茶杯和品牌收尾 | 05 收尾画面 + 简短商店封面动效 |

建议使用9:16竖版，1080x1920输出；如果用在TapTap小游戏，应优先遵从官方实机录屏约束，直接录制真实操作视频而非用此分镜动画替代。
