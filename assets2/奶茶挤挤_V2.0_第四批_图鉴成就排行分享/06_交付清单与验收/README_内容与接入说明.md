# 《奶茶挤挤》V2.0 第四批——图鉴 / 成就 / 排行榜 / 分享

## 交付范围
依据原版`P3-B` 20项 + `P4-B` 28项 = **48个资产ID**。实际产生**41项独立PNG**（不少于41张PNG），其中可从第一批继承SVG的图鉴详情沿用原SVG；其余矢量图另附SVG，成绩分享卡附布局JSON。**3项程序生成、2项平台资源、2项未来候选**以独立说明文档登记，不伪造PNG。

## 路径说明
- `00_概念参考_非实机/`：前一次生成的整体美术概念板，含演示成绩和人物，不是实机截图，不能直接作为上架提审图。
- `01_P3B_排行榜分享与晃杯券/`：7类功能图标、排行行与本人高亮、默认头像、金银铜奖牌、晃杯券、2套成绩分享卡。
- `02_P4B_小料图鉴派生/`：9份图鉴详情 + 9份统一剪影，复用第一批已绘制的精灵。
- `03_P4B_图鉴成就外观控件/`：图鉴/成就/外观图标、图鉴卡底、发现角标、通用成就章、成就分享背景。
- `04_整页效果图_非实机/`：4张整页示意，玩家昵称、积分/排名等只是占位内容；真实游戏数据请由引擎与平台接口提供。
- `07_引擎和平台资源说明/`：程序和平台项说明、未来候选占位说明。

## 设计限制和接入要点
- 不增加未确认的金币、钻石、广告奖励机制；原概念板出现的数值和形象均为美术示意。
- `share_result_background` / `share_record_background` / `share_achievement_background`：750×1000，原品牌主图保留，实际分数、头像、昵称和真实平台分享码必须动态覆盖，底部留有入口区域。
- 排行榜必须依据接口和授权使用真实昵称与头像。个人无登录/授权时应当使用默认头像并隐藏不适用信息。
- 图鉴详情源自第一批独立精灵，不重新绘制；剪影按原精灵alpha追踪为矢量轮廓，**不包含静态问号**。
- 行底、图鉴卡需做Cocos九切适配验证；图标触控区域需引擎适配；弱动态/隐藏信息状态仍需联调。
- 成绩分享卡是带栅格咖啡店背景的PNG布局图层组合，不是完全矢量原画。布局JSON用于维护动态覆盖区域。
- 已完成文件层级技术检查，但**不代表视觉终审、玩法/数据一致性审核、Cocos集成、真机性能或发行提审合格**。

## 依赖
第一批小料原始SVG+512×512 PNG、第三批杯型组合参考；使用了第一批已生成的奶茶店背景。字体只在组合效果图渲染，独立PNG里没有动态文案。
