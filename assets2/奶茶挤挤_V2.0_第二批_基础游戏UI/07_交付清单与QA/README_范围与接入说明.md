# 奶茶挤挤 V2.0 — 第二批基础UI

第二批严格对应原213项图像表中的 P1-06 / P1-07 / P1-08 / P1-09 / P1-10 / P1-11。

## 交付
- `01_图标_18项/`：开始、继续、暂停、设置、关闭、返回、重开、主页、音乐开关、音效开关、弱动态、晃杯、说明、警告、确认、下一步。各附SVG、192px主渲染、96px和48px透明PNG。
- `02_面板_5项/`：弹窗、HUD、预告框、提示、结算，规格严格沿用源表。九切边界须由Cocos按表配置。
- `03_控件徽章_6项/`：开关轨道/圆钮、音量轨道/圆钮、新纪录徽章、麻薯徽章。
- `04_特效与引导_7项/`：合成环、星光、食材屑、投放光点、麻薯里程碑星、手势移动/松开。没有承诺动画帧集；需游戏程序驱动缩放、旋转和透明度。
- `05_界面效果图/`：暂停、设置与结算示意，不等同实机；独立素材总览。
- `06_视觉参考_非运行素材/`：AI生成视觉拼版，仅供统一画风，含尚未开发的演示功能，不可直接导入游戏逻辑。
- `07_交付清单与QA/`：权威ID对应表、文件清单和自动检查结果。
- `08_引擎动态元素_实现说明/`：合成动态例子和七项P1-11程序元素实施原则，不生成假的静态数值图片。

## 技术边界
- 源文件SVG提供可编辑向量基础，PNG是可加载工程的候选资源，但尚未经Cocos实机集成终审。
- 通过了独立文件、格式、尺寸和透明边技术检查，不代表美术终审通过。
- 第一批已存在的12个按钮状态和经典杯层沿用，不重复复制。
- 字体、菜单名、积分、定时器由引擎根据实际业务动态绘制；宣传概念画中的金币、钻石、礼包不能视为需求。
- 所有资源只在本次对话容器中落地，不等同已经自动保存到用户GitHub/Codex仓库。
