# 程序生成元素（不在静态PNG产物中）

- `ui_tutorial_merge_example`：程序使用两枚相同级别的实际素材实例绘制，动画由逻辑触发，不应固定到一张示例图
- `gen_danger_line`：按CupGeometry危险y坐标运行时绘制虚线；需隐藏在危险未达到时；颜色亮度符合提示要求
- `gen_drop_guide`：运行时计算投放x, 将虚线从预览小料延伸到杯口内, 不参与碰撞
- `gen_score_text`：分数/飘分/纪录动态文字；font需合法使用；不要在美术PNG中烘字
- `gen_danger_countdown`：物理碰撞和危险计时一致；动态3/2/1，暂停冻结计时，绝不写死图片
- `gen_shake_count`：晃杯剩余次数与冷却计时运行时生成，禁用状态不可点击
- `gen_modal_dim`：引擎绘制可调alpha黑色遮罩，遮罩应覆盖背景UI但不覆盖对话框内容
- `gen_loading_spinner`：程序旋转单独图元或原生进度控件，按真实加载状态结束

提醒：表中含 P1-10 的程序合成示例和 P1-11 的7项，共8项，属于业务逻辑，不在美术交付中伪造。
