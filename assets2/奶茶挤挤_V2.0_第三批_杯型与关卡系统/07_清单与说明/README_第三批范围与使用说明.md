# 《奶茶挤挤》V2.0 第三批 | 杯型与关卡系统

本包是按照原 P3-A **48个资产ID** 重建的、与奶油白/焦糖黄/巧克力描边美术风格相容的**SVG+PNG静态工程试制交付**。它并非第三批通过引擎/真机验收的最终锁版。

## 文件结构

- `01_整体概念图_非实机/`：先前生成的4张概念图，不能直接用于提审或充当游戏界面。
- `02_五款杯体_7层独立/`：新增的椰香、芋泥、黑糖、麻薯共28层，每层750×1000。经典杯七层来自第一批，此处仅生成一致性预览。
- `03_五款杯型卡片/`：经典+四款新增，480×600 SVG和PNG，底部30%留程序排文字。
- `04_页签与功能图标/`：4种页签+6种功能图标；48px/96px PNG和SVG。
- `05_关卡面板与亮边/`：一个280×400空卡底和一个256×256透明解锁边框。
- `06_预览与质检/`：五杯叠层、菜单卡、图标状态展示。
- `07_清单与说明/`：48项逐项manifest、程序契约、静态验收和待办。

## 杯体图层复合顺序

参阅 `Cocos_运行时与杯体层级说明.md`。重点：画布统一、禁止自动裁切、不能把营销成品饮料视为真实物理杯，小料实体由游戏引擎生成并按前后杯壁遮挡。

## 重要边界

`P3A-07`的3项 `gen_*` 是程序生成，按原资产合同**不得伪造PNG**。真实账号/云同步能力取决于实现情况，这里仅提供图标，不代表功能已经开发。关卡图为概念，不保证当前实际游戏有图中的星级/解锁机制。

## 使用建议

Codex/Cocos中先导入4套杯体分层PNG，使用CupGeometry导线进行重合测试，观察杯口、小料碰撞与高亮的视觉/物理一致性；此后再将5张卡片和页签图标接入选择页。
