# 第三批 P3-A 运行时元素实现契约

- `gen_skeleton`：异步列表加载时由Cocos绘制圆角灰白占位矩形，不依赖静态PNG；加载完替换成真实杯型卡。
- `gen_locked_overlay`：程序根据真实解锁条件为对应卡片叠灰/透明蒙层、复用 `ui_icon_lock@96.png`，文字与解锁门槛由运行时绑定。
- `gen_error_empty`：无网络、无数据、失败状态由Cocos使用已有基础面板及 `ui_icon_offline@96.png`，搭配运行时提示及重试操作；不伪造网络结果。
- `ui_stage_*_card`：底部区域保留动态名称/纪录/状态文本，不允许贴固定成绩截图。
- `ui_btn_tab_*`：九切仅处理底图，文字图标置于单独节点；禁用态同步阻止点击。
- 杯体组合应按 `back`→`tea`→`rim_back`→`base`→`label`→`front`→`rim_front` 的视觉次序，碰撞小料节点应插入杯后景与杯前景之间；具体遮挡顺序在游戏中测试。
- 五款杯都遵守世界原点(0,200)、导出画布750×1000，经典基准开口顶部1060DU/底部260DU；横向缩放经典1.00、椰香0.95、芋泥0.90、黑糖0.85、麻薯0.80。
- 本版以原始设计合同复核，不宣称已通过物理或真机集成。
