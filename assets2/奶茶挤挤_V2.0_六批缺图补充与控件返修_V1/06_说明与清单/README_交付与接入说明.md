## 拼接与用法

原背景尺寸：750×1334。顶部延展贴在 y=-400..0，底部延展贴在 y=1334..1734；对应拼接效果见`05_预览与核验/长屏延展_拼接效果.jpg`。两条连接边已按像素数组比较：**0差异**。该保证只代表连接边颜色一致，真实长屏显示仍需观察灯具、绿植、木纹的视觉延续。

`spr_cup_shadow`放在杯子节点下，避免放到杯体图层里；强度和宽度可以按杯型缩放。

`ui_slider_fill_full`默认是全长素材。Cocos请用Mask/Sprite.fillRange或裁剪宽度控制填充，数值0~1。禁止把固定百分比永久烘焙进轨道背景。
