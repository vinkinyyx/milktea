|---|---|---|
| `10_effects_showreel.mp4` | 20秒连续动态展示，640×640 | 快速检查视觉方向；不是游戏实机录屏 |

## 10项动画与项目逻辑的边界

1. 小料掉落：运动示意；真实掉落必须由现有物理模拟控制，贴图仅用落地时的软弹效果。
2. 小料碰撞：同一碰撞事件下的视觉形变，不更改碰撞体或小料状态。
3. 同级合成：只在业务规则确认两相同等级有效合并之后执行，不在动画里重新计算等级。
4. 连击：数值和文字必须从实际游戏结算状态更新，不使用视频演示中的固定“+360”。
5. 晃杯：视觉杯体回摆；杯内小料的实际移动交给物理引擎或已有晃杯机制。
6. 危险线：由真实溢出判定控制，约1.1Hz柔和脉冲，避免强烈闪屏。
7. 按钮：只作用于UI图案，不改变点击区域。
8. 结算：动态显示真实得分/实际星级；不添加不存在的金币或物品奖励。
9. 猫咪：基于已有原画制作轻微整体摆动和庆祝，**不是已经完成的分层骨骼动画**；真正的挥爪关节动画仍需原画分层。
10. 页面切换：位置和透明度变化；真实页面栈和输入阻断仍由游戏原有系统实现。

## 对接 Codex / Cocos Creator 3.8

1. 将 `cocos_creator_3_8/MilkTeaV2Effects.ts` 和 `Example_Animation_Events.ts` 放入 `assets/scripts/effects/`。
2. `assets/` 下PNG放到 Cocos 项目的 `assets/resources/effects/v2/` 或实际使用的资源目录。
3. 在场景 Canvas 或 EffectsRoot 挂载 `MilkTeaV2Effects` 组件，通过 Inspector 绑定视觉层节点、危险线节点、猫咪节点、结算分数 Label、星星等。
4. 在**原有的**落地、碰撞、合成、连击、晃杯、溢出状态、按钮事件、结算、打开页面回调内调用对应方法；不要制造第二套碰撞/合成判定。
5. `transparent_effects/<name>/<name>_NN.png` 可通过编辑器制作 AnimationClip 逐帧播放，也可导入 `_sheet_4col.png` 并在图集编辑器中按192×192切分；提供的JSON只是简单帧网格描述，不是完整的 Cocos 内置序列化资产。
6. 实机验收优先覆盖：窄屏与9:20长屏、真物理下落、多个同时合成、暂停恢复、低性能安卓机、弱动态设置、切后台恢复和音效同步。

## 重要提醒

- 交付视频为**真实逐帧运动效果演示**，不是幻灯片；也不是已构建的微信/抖音小游戏，更不是可以直接提交官方审核的实机视频。
- TypeScript源代码是按Cocos Creator 3.8 API写的**集成示例**。没有在用户的游戏工程中运行、编译或真机测试，需由Codex根据现有Prefab/组件结构绑定后联调。
- 猫咪透明素材从既有概念图做边缘提取，仅适用于轻度动画预览；重度角色动作建议使用真正分层的角色源文件。
- PNG序列支持透明背景；MP4/GIF预览是合成背景画面，不应直接作为游戏中的精灵图或视频层替代物理动画。
- 动态效果建议目标60FPS，中低端设备最低稳定30FPS；关闭“减少动态效果”前应测试粒子数量与特效层级。
