# 《我是CEO》项目落地模板

> 本文件是为当前游戏**示例化**的设计映射，不代表已读取该游戏真实源代码，也不证明游戏已经具备这些能力。使用时必须基于代码实际状态复核。

## 已知玩法与一期边界

- 游戏：**《我是CEO》**，竖屏 2D 轻经营沙盘，偏信息面板与部门卡片，挂机友好。
- 一期经营：创建公司（自定义/随机名称、CEO 姓名与属性）、单一主营业务、多部门（利润中心/成本中心）、招聘和裁员（赔偿）、年度经营结算与稳定盈利。
- 经营排名：经营年限与企业总资产，不预设排行平台一定已接好。
- **关闭公司**：玩家主动二次确认后清除当前经营存档、CEO 成长、员工/部门、资金资产、年份、排名和新手引导，重新创建公司；平台账号与法律要求保留的必要合规记录不属于游戏经营存档。
- **音频**：“全部音乐与音效”总开关持久化；音乐与音效分项开关可以存在但总开关关闭时必须静音。
- 技术栈/正式包体类型：当前**未从真实代码核定**，不可默认 H5、Cocos、Unity 之一。

## 推荐的技术最小路线（仅在引擎实情符合时）

若已有 HTML/JS 实现并希望尽量低成本，先评估**平台托管 H5**，以官方 H5 MCP/上传规范为准。若项目已经使用 Unity/Cocos 和 Tap 小游戏适配，保持其现有技术路线，**不要为了广告而重写项目**。先接一个激励视频广告位，再考虑排行榜/云存档等附加能力。

## 优先级和验收

1. 找到真实工程、生成 `project-profile.md`，锁定技术形态。
2. 追踪 ICP 审核状态并补齐隐私政策/检测材料；软著冲突向平台工单核实。
3. 产出真机可运行包并完成完整经营循环：命名→招聘→经营→年度结算→重进。
4. 测试关闭公司二次确认、经营数据完全清除而账号记录仍依法处理。
5. 测试音乐/音效总开关在关闭与重新启动后保持一致。
6. 9:20 游戏画面不强行拉伸成 9:16；平台实机录屏使用真实 9:16 合规画面。
7. 用真实运行游戏截取至少三张实机图，制作横图/方图；完成版权检查。
8. 激励视频首版限定“用户主动点击”入口，广告失败或提前退出时不能领取额外奖励，正常经营不受影响。
9. 如果接排行榜，需约定“企业总资产”、“经营年限”的榜单数据定义、同分规则、重置同步策略、防刷和是否可更改；避免把游戏本地重置误删全局账号。
10. 上传后用 TapTap 实际测试入口执行 iOS/Android 对照验证，保留状态证据和平台返回结果。

