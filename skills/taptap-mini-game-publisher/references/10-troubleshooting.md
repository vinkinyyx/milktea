# 故障定位和工单写法

## 优先收集的证据

- 游戏 ID 与发行主体（但不要公开身份证号/银行信息）。
- 实际形态（H5、Tap Mini WebGL、制造、APK）及引擎版本。
- 发生在构建、上传、解析、运行、广告、备案、提审的哪一步。
- 包体版本、文件 SHA256、构建输出日志、平台错误原文/错误码。
- 可复现设备与系统、发生时间、网络条件、最小复现步骤。
- 后台资格状态、是否因身份/版权/广告数据错误被拒。

## 常见故障与下一步

| 症状 | 第一层排查 | 不要做 |
|---|---|---|
| 上传不识别 ZIP | 是 Tap 专用构建文件吗？压缩目录层级、转换器版本、后台游玩形态是否一致 | 反复改 zip 扩展名；擅自套用 H5 上传接口 |
| 首包超限 | 查看当前后台真实限额，再优化图片/音频、考虑 WASM 分包 | 直接认定 60MB 或 20MB 一定是唯一标准 |
| 页面白屏/打不开 | 资源路径、运行环境 API、控制台日志、首屏异常、真机支持 | 只根据桌面浏览器成功就报测试通过 |
| 登录失败 | AppID/环境、登录 code、服务端 code2Session、网络和 token 失效 | 把 client secret 放前端；转用 APK SDK 盲试 |
| 广告不显示 | 媒体/广告位审批状态、所用形态、adUnitId、测试配置、频控、无填充、弱网 | 伪造观看成功或强制多次重试 |
| 看完广告未给奖励 | 事件监听、官方完成回调含义、网络竞态、幂等日志 | 没有完整观看就提前发奖 |
| 软著审核要求与入门文档不一致 | 对比资质页面、当前发布形态、内购类型；发工单书面核实 | 断言“个人一定豁免” |
| ICP审核中 | 查看平台备案状态、负责人的短信核验、是否退回补件 | 重复备案、伪造核准号 |
| 隐私检测不通过 | SDK清单、首次弹窗、真实政策链接、权限时序、拒绝后行为 | 把第三方广告 SDK 隐藏在文案之外 |
| 素材审核不通过 | 对照真实游戏、清晰度、图标/首图规则、视频水印、9:16 | 用概念图当实机录屏 |

## 可复制工单模板

```markdown
标题：【小游戏发布】<游戏名> / <问题类型>
开发者类型：个人（身份信息已在后台认证）
游戏ID：<ID>
发布形态：<H5/Tap Mini WebGL/制造/APK>
商业模式：<IAA/无付费/IAP>
当前状态：<审核中/错误码/被驳回>
复现步骤：1... 2... 3...
实际结果：<原始错误文案>
期望结果：<具体期望>
相关规范：<官方文档URL>
尝试过的排查：<简要>
请求确认：<一个或几个可直接回答的问题>
附件：<脱敏截图/日志/校验信息，不含个人敏感信息或密钥>
```

## 验证结果标签

- `STATIC_PASS`：文件/尺寸/格式静态检查通过。
- `LOCAL_RUN_PASS`：本地浏览器实际运行通过。
- `DEVICE_PASS`：平台环境真机测试通过。
- `PLATFORM_VALIDATED`：平台上传/自动校验通过。
- `REGULATORY_APPROVED`：按对应游戏当前真实后台显示已通过资质。
- `REVIEW_APPROVED`：游戏平台人工审核通过。
- `LIVE_CONFIRMED`：实际玩家可访问游戏、不是预览包。

不得用较低层级成功代替高层级审核成功。
