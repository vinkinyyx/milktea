# 奶茶 P3 V2 总包使用说明

- **直接用于游戏的静态PNG/SVG**：`P3-A_V1/`、`P3-B_V1/`、`P3-C_V1/` 对应子文件夹，按原始资产ID查询。
- **审核结果**：`QA/P3_完整验收与风险报告_V2.md` 与 `QA/P3_74项逐项验收清单_V2.csv`。
- **源规格**：`QA/Original_Spec/`。
- **演示不是运行资产**：`previews/`、 `*_PREVIEW_ONLY.png`，不应当作独立游戏资源。
- **分层源**：四款杯体为独立SVG及合成SVG；P3-B UI为SVG；P3-C的封面与截图是ORA源文件。
- **需要真实平台授权**：P3-B中的头像与入口码是接入合同，不包含用户数据。
- **未提供真实商店截图**：P3-C四项是待替换模板，禁止直接宣称实机截图或上传应用商店。
- **CupGeometry**： P3-A的几何导线按文档反推，无法代表引擎权威导线；必须由开发提供引擎比对图后才算物理验收。
- **授权**：本包不包含第三方平台许可、实际用户肖像许可或商店上架授权，需在发布时独立核实。

V2以原V1各批内容为基线，新增独立复审记录、模拟Canvas逻辑测试、跨批次检查与完整归档；没有无依据地改变已确认画风。
