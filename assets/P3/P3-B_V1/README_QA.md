# 奶茶 P3-B：排行榜、晃杯券与成绩分享（20项）

本包严格按原始 image-elements.json / P3-B资产清单生产。20个资产ID中：15个new_draw、1个derived、2个engine、2个platform。不是20张手画PNG；引擎生成和授权平台提供的元素不会制作假的图片。

## 交付结构

- `source_svg/`：16个独立可编辑矢量源（7 icon、2 panel、5 detail、2 share）。
- `export_png/96` / `48`：7枚图标两档导出，共14 PNG。
- `export_png/runtime`：9个运行素材PNG（2行底、1头像、3奖牌、1票面、2分享卡）。
- `export_png/master_2x`：9个2×大图导出，方便复核与美术修改。
- `runtime/`：名次动态绘制、服务器时间的券到期显示模块。
- `platform/`：真实头像/入口码的集成合同，不内置虚假的真人头像或二维码。
- `docs/share_runtime_layout.json`：分享模板的安全区域及动态文本槽。
- `qa/`：20项清单、结构检查报告、九切检查报告和图片预览。

## 注意

- 分享卡源1500×2000，运行PNG750×1000，四边48px安全区，底部180px入口区域。分数、玩家头像、真实游戏画面、姓名、二维码在运行时填，不应被静态PNG烘焙。
- 排行行底330×48，九切12/12/12/12；本人的行用浅绿强调。
- 7个UI图标为192×192 SVG，导出96、48透明PNG，线宽不低于4px（96档）。
- `ui_icon_verified`是原创提示图形，不是平台官方认证标志。
- `platform_share_entry_code`不制造假的QR码：必须在目标平台真实生成并通过设备扫码验证。
- 排名程序采用竞赛排名法处理同分（例如1、1、3）；超过比例只有服务端数据有效时才显示。
- 晃杯券计算使用可信serverTime。默认示例截止于北京下一个午夜；如服务端提供真实expiryAt，优先实际值。

## 验收边界

尺寸、像素格式、可编辑SVG有效性、透明、无静态动态值、九切和静态布局检查可在本包自动校验。真实授权头像、真实平台入口码、排行榜接入、服务器时钟同步、设备实际缩放和深/浅背景组合需要游戏集成验收，不能误标为全部过审。
