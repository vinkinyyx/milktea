# 奶茶 P3-B 完整交付与验收报告 V1

日期：2026-10-27；生产基线：P1 V3 / P2 V2 / P3-A V1。

## 资产总量

- 20/20 个资产ID均有合同或独立可用源文件；16个图片资产，2个engine，2个platform。
- 16份独立SVG源，32张PNG（含7图标×96/48双档，以及9图像资产的runtime/2×双档）。
- 2个JS动态模块，1份平台接入JSON合同，分享模板坐标定义。

## 完成的静态验收

- 20个资产ID对原始清单逐个对应，PNG规格、通道、sRGB ICC信息、SVG解析全部合格；文件级错误 = 0。
- 7枚192源图标分别导出96/48，复核浅色按钮下可识别，不能直接放在同色深棕底上。
- 2个330×48行底九切12/12/12/12，放大到495×64后四角逐像素未改变。
- 3枚奖牌颜色区分明确，无烘焙名次数值；默认头像为虚构奶茶卡通图标，非真人。
- 晃杯券画面无写死余额、有效期或固定次数；平台头像、码均未伪造。
- 两张750×1000分享模板保留48px安全距离及底部180px真实入口区；1500×2000母版使用按用途命名的8组可编辑矢量元素。
- 动态模块7项逻辑断言通过：并列排名、空排名、无效超过比例、北京时间24点、到期秒数与过期状态、服务端时间缺失显示。

## 未能由静态美术验收的项目

1. `platform_user_avatar`：需用户授权、平台合法头像URL与默认头像回退。
2. `platform_share_entry_code`：需实际游戏发布后由平台真实签发，必须用真机扫码验证。
3. 排行榜数据/超过比例：需要真实后端数据和同分排序规则联调。
4. 晃杯券的真正服务器到期策略、客户端时钟偏移及到期刷新。
5. 真正游戏分享截图、最长名字、缩略图、小屏安全区及平台上传尺寸。

以上是**静态素材交付完成**，不是整个P3-B功能已完成实机/后端集成验收。

## 文件入口

- `source_svg/` 所有可编辑源文件。
- `export_png/96`, `48`, `runtime`, `master_2x` 输出图。
- `runtime/` 动态Canvas模块。
- `platform/runtime_contracts.json` 真实数据输入合同。
- `docs/share_runtime_layout.json` 动态注入坐标。
- `qa/` 资产清单与测试报告。
- `previews/` 原图组合与深浅背景的质量示意。
