# P4-B 图鉴、成就与外观 — 逐项制作及验收 V1

## 结论
原始28个资产ID已逐项建立交付入口；26个必需项中，25项提供可独立使用的运行图片及源文件/来源追溯，1项为Canvas绘制的动态问号；2个候选槽在原需求中尚无尺寸及创作批准，按规范保留配置，不生成无依据的图。静态文件检查：**通过**。

## 数量及来源
- 九级小料：9张192x192中性色剪影、9张512x512详情图，均由P1 V3原始1024x1024 PNG重采样派生；另导出96/256像素运行尺寸，共36张PNG。
- 新绘图：3个SVG功能图标（192 SVG；96与48 PNG）、1个图鉴格底板（360x420 SVG；180x210 PNG）、2个SVG徽章（发现章96 PNG；通用成就192 PNG）。正式SVG共6份。
- 分享卡：P3-B `share_result_background.svg`派生1500x2000 SVG和750x1000 RGB PNG（附1500x2000高清PNG）；不含任何虚构的玩家数据、二维码。
- 程序元素：`gen_album_question.mjs`，仅动态绘制问号。
- 未立项装饰：`candidate_cup_pattern`、`candidate_table_theme`，只有JSON规格占位，不生成图片。

## 验收项
- 28项原始ID覆盖，26个required、2个candidate；正式PNG资产25项。
- 25张正式PNG：尺寸、颜色ICC、透明/不透明规则及命名检查；有SVG的7项进行等尺寸逐像素重绘检查。
- 九级详情的每个像素均对应P1 V3母版的LANCZOS重采样，未重绘。
- `ui_panel_collection` 16px四边九切，拉伸到310x340后的四角像素保持一致。
- 未发现剪影不烘焙问号，游戏运行时叠加；不虚构第10级配料。
- 分享卡内容区仅为背景，真实玩家名称、分数、已解锁状态及平台码均由游戏运行时决定。

## 后续真实游戏验收项
- 验证小游戏的实际Canvas、设备DPR和画面缩放是否正确；48 CSSpx触摸区由业务UI实现，图片不自动保证点击区域。
- 验证图鉴的已发现状态必须来自存档数据，未发现不得泄露贴图；问号对比度需按主题实测。
- 分享卡在真实平台中，需要实机生成用户头像/成就图片和平台授权入口码；本包不提供伪造数据。
- 候选杯纹样/桌面主题没有获批设计简报和规格，后续应新建独立资产ID及任务。

## 文件说明
`export_png/`为运行/目标图片；`export_png/runtime/`是便于直接运行的额外尺寸；`source_svg/`为可编辑矢量文件；`source_refs/`记录P1源素材SHA256与所在文件；`runtime/`为动态问号代码；`candidate_specs/`明确未启动的候选元素；`qa/`为可复核验收清单；`previews/`只是汇总预览，不是正式图片。

检验问题：无静态文件级问题。
