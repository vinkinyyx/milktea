## 保留的限制

1. TapTap当前官方[推广物料规范](https://developer.taptap.cn/docs/store/release/publish/material/)的16:9宣传图建议1920×1080，除游戏名外不得添加其他宣传性文字，实际渠道审核模板仍须以对应游戏后台为准。
2. `marketing_tap_cover`经本地重新组版可作为上架候选美术，但没有得到实际平台审核批准；裁切、平台角标和最终安全区仍待真机/后台验证。
3. 微信图标导出512/256/128仅为开发候选，非对官方账号后台当前尺寸的保证。
4. 不含伪造的平台认证标识、平台审核成功证明和任何真实设备测试结果。
5. `P4-D_4assets_contact_sheet.png`为组合预览，不是游戏正式可加载素材。
