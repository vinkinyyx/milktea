# 奶茶 P4-C 广告相关素材 · V1

## 原始范围
P4-C 在213项原清单中只有 2 个资产ID。

| ID | 正式制作方式 | 交付现状 |
|---|---|---|
| `ui_icon_ad_play` | 新绘192×192 SVG + 96/48 RGBA PNG | **静态技术检查通过** |
| `platform_ad_badge` | 平台提供 `(runtime)` | **待真实SDK或发行平台提供**；仅交付接入合同，**不得假造图片** |

## 美术风格
继承P1～P4奶茶UI：深棕#3F281E、奶油#FFF8E8、焦糖#EFB85F；统一圆角、45度高光；视频框+播放三角；不绘制真实广告商Logo、文字、动态按钮状态。

## 文件与工程规则
- source_svg/ui_icon_ad_play.svg 是真正的矢量可编辑母版，非PNG外贴的SVG。
- export_png/96 和 /48 各含一张独立PNG；8bit straight RGBA+嵌入sRGB ICC。
- pivot=(0.5,0.5)，九切无，触摸区由程序设置≥48 CSSpx。
- 边框SVG 11px，96px运行版本约5.5px，不小于4px。
- 关闭/禁用状态由程序调色并真正禁用交互，不重复绘图。

## 验收结论与集成依赖
1. 静态资产：尺寸、透明边、sRGB、SVG可编辑、文件齐备检查通过。
2. 平台资产：`platform_ad_badge` 必须由官方SDK或授权渠道按现行要求提供；不得用当前概念展示图或自造广告标志替代。
3. 接入待验：真实广告关闭/失败场景不能领取奖励；触摸区、可用性、广告告知和SDK平台标志需实际机型验证。
4. 本批**未**完成平台发布验收，不能声明2张图片均已制作。
