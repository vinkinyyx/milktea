## 结构

- `source_svg/`：8份SVG母版；
- `export_png/96`, `export_png/48`：10张独立图标PNG；
- `export_png/runtime`：3张正式PNG（挑战面板1、分享卡2）；
- `export_png/master_2x`：上述3张2x高清PNG；
- `runtime/`：2个渲染模块、逻辑测试、分享卡动态区域合同；
- `platform/`：入口码接入合同，无伪造图像；
- `qa/`：逐项记录、各检查项与哈希；`previews/`：非运行素材的预览。

所有交付图片独立存储，不将联系人头像、平台Logo、动态文本烘焙进PNG。底图为本项目原创SVG代码绘制或从获批的P3-B项目源文件派生，不附带第三方字库文件。
