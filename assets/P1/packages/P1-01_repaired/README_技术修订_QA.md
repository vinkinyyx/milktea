# P1-01 第一批九级小料母版：技术修订 V2

## 修订原因
旧批次为1254×1254像素并带有低透明度杂点，和规范要求的1024×1024母版不一致。

## 已修订
- 9张母版全部1024×1024 RGBA PNG，真实Alpha透明、无背景、主体中心配准。
- 清除背景微弱孤立杂点，使外轮廓更贴合物理碰撞圆；半径外廓误差最大1.70%，中心定位误差最大1.12px。
- 每种小料128/256/512像素导出（请使用@128/@256/@512后缀）。
- 原始高分辨率图仍保存在先前批次，不替代本修订包。

## 尚未通过的关键点
- 当前源图是单层栅格渲染，缺少要求的base/texture/highlight/optional_face可编辑独立图层，**不得标记为完整交付/最终锁版**。
- 引擎物理碰撞测试、实机缩放、视频压缩回放与真实UI对比尚未执行。

## 使用
- source_master_1024：1024像素暂行母版。
- exports：27张分辨率导出文件，用于精灵试集成。
- P1-02中另有9张96×96缩略图从本母版派生。
