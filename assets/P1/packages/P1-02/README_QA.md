# 奶茶 P1-02 素材交付与复核

## 批次
- 第二批共12张独立PNG：9张96×96小料缩略图、3张256×128单色表情覆盖层。
- 9张缩略图均从同名第一批母版**派生**，不重新绘制；保持角色材质与外观一致。
- 3张表情为可选资产，附可编辑SVG。眼嘴统一锚点，位于透明画布中部。

## 第一批技术修正
- 原始AI渲染PNG为1254×1254，且边缘存在低Alpha孤立杂点，故旧版不能视为通过交付。
- 已将第一批9张母版处理为1024×1024，去除孤立杂点并调整外廓接近圆形，用于派生本次缩略图；另生成128、256、512三个独立运行导出尺寸。
- 修正是技术加工，不等于重新绘制，仍需在游戏引擎中实测碰撞/缩放。
- 重要限制：九张第一批母版仍为**单层栅格图**，不具备规范期望的base/texture/highlight分层可编辑原稿。不得标记为完整美术源文件合格。

## 本批检测
- 12个文件均与资产ID同名、一图一个PNG、无UI文字/背景，均含真实透明Alpha。
- 9张缩略图输出尺寸96×96，3张表情256×128。
- 图片来自统一第一批源，因此不会发生二次生成的风格漂移。
- 已提供黑白/灰/棋盘对照预览；游戏引擎48DU运行截图、最小分辨率可辨性等仍需开发实机验收。
