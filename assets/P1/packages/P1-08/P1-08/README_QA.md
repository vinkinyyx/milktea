## 绘制方式与不可烘焙内容


- 风格采用前批P1-05按钮一致的奶油纸感、柔和渐变、暖棕外框与局部金色点缀。
- PNG透明背景、无动态标题、姓名、分数、倒计时、头像或平台标志。预览图里的示例文字是后贴的，**不包含在运行PNG中**。
- 2x SVG母版的逻辑坐标为运行PNG的1x坐标，因此CSV九切边距按**导出运行PNG像素**记录，不是2x SVG画布尺寸。
- 每个SVG中提供六个可编辑分组（轻投影、纸张主体、高光、内倒角、细描边和边角点缀）；UI动态内容必须由开发在独立节点中呈现。
- 较窄的HUD、Toast不应在原生高度内固定嵌入文字，竖屏排版应由游戏端决定。

## QA结果

逐项检查项目：尺寸、2x SVG参考画布、RGBA、全透明画布外边缘、中心不透明、九切边界有效、四角数值相同、SVG有六个分组、无嵌入文字/外部图片、导出文件非空，全部通过。具体机器检验值见 `qa/asset_qa.json`。

九切测试：按照导出PNG标注裁成九块，拉伸中心及四条边，实测四角像素差最大为 **0**。每项都有 `qa/nineslice_stretch/` PNG可供人工检查。

## 已知限制与下一步验收

1. **未做实际引擎测试**：需要在75/100/150%缩放、375 CSS像素窄屏、安全区、最短/最长文本、禁用态与低端机帧率下复验。
2. 用户指定的“内留白24DU”属于布局安全距离，面板皮肤本身不含排版；请开发侧对动态内容设置对应layout padding。
3. 本批视觉检查为静态预览，并不宣称已通过游戏物理与动画遮挡测试。
4. 本次交付含可编辑SVG，但并非原生PSD/Krita多图层工程，满足规范允许的SVG可编辑源方案。
