## 与P1-06的视觉继承

- 延续P1-06的深棕描边（约#3F281E）、焦糖棕线性渐变（#996744→#653C2B）和浅奶油高光。
- 图标内容居中、有透明边距；文本、按钮皮肤、点击热点未烘焙到图像内。
- 音乐关图标复用P1-06音乐开的音符几何，仅移除声波并加斜杠，保证启停切换一致。
- 音效开关共享扬声器轮廓，靠声波／斜杠区分。下一页双箭头区别于P1-06单箭头继续。

## 工程验收

1. XML/SVG可解析、母版192×192、无嵌入栅格，九图每个独立。
2. PNG均为RGBA，分别96×96及48×48，包含sRGB ICC配置。
3. 全部四角alpha=0，非空，主体距离边缘至少2像素，没有可见裁切。
4. 九张图像纹理哈希互不重复；绘制了透明背景、浅背景、暗背景、P1-05圆形按钮和真实48px预览。
5. 原规格的“在96px图笔画至少4px”由主要轮廓宽度（SVG≥8px）满足；少量局部装饰高光可小于该值，不属于主笔画。
6. 保留局限：深棕线稿在深棕背景对比不足，应选择奶白按钮或由UI程序切换高对比皮肤；实际点击框≥48 CSSpx、开关同步、弱动态行为、移动设备可读性仍需游戏集成测试。
