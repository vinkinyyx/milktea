# 奶茶 / P1-09 交互控件与成就徽章 — 验收说明

- 状态：**静态资产检查通过**；实际游戏引擎集成、交互响应、跨设备测试未实施。
- 来源：`/奶茶/image-elements.json`（handoff-v0.2）。批次 6 个必需 `new_draw` 资产ID。
- 工艺：6 个独立可编辑 SVG，6 个运行PNG（原清单规定的准确尺寸），6 个 `@2x` PNG，全部透明 RGBA + sRGB ICC。
- 色彩方向：暖棕外描边、奶油纸高光、焦糖与金色徽章，延续 P1-05 / P1-08 UI。
- 文件名和导出规格详见 `qa/asset_manifest.csv`。

| 资产ID | 内容 | PNG尺寸 | 实际用途 |
|---|---|---|---|
| `ui_toggle_track` | 开关轨道 | 128x64 PNG | 开关开/关用程序颜色与圆钮位置，不仅用颜色说明。 |
| `ui_toggle_knob` | 开关圆钮 | 64x64 PNG | 边缘清楚，移动由程序控制。 |
| `ui_slider_track` | 音量滑杆轨道 | 256x24 PNG | 平直，两端圆角，可横向九切。 |
| `ui_slider_knob` | 音量滑杆圆钮 | 64x64 PNG | 触摸框另放大，不改变视觉半径。 |
| `ui_badge_record` | 新纪录徽章 | 256x128 PNG | 不含“新纪录”文字，图形为原创星章。 |
| `ui_badge_mochi` | 首次麻薯徽章 | 192x192 PNG | 仅里程碑装饰，不暗示游戏胜利结束。 |

## 技术校验
1. 6份SVG可解析并已从SVG直接渲染出每个PNG；每幅独立文件，无额外标题、数字、平台标记。
2. 运行PNG全部为规格尺寸，RGBA透明、画布最外一像素全透明；sRGB ICC嵌入；@2x保留同一设计比例。
3. `ui_slider_track` 的两端保持圆角，16像素端帽的512×24横向九切延展测试，两端像素与原图完全相同。原JSON字段九切为 `none`，16像素为建议适配策略，不擅改正式清单。
4. 开关的开关状态、滑杆填充、位置由引擎绘制，不复制多个不必要的状态素材；预览中的交互数值仅为模拟布局。
5. 圆钮视觉圆大小与触摸区域不同，移动端点击区域应由实现方增至48 CSS等效像素以上。
6. 徽章无烘焙文字，星章原创绘制，麻薯里程碑不暗示通关。

## 限制与后续验收
- 静态QA不是游戏中完成的测试：需开发在375宽竖屏、深浅背景、禁用态、实际设备DPR和低端机纹理占用下二次验收。
- 深棕线条叠加深棕背景时对比度可能较低；图标应置于浅色承载面。
- SVG使用原生渐变、路径和分组，可编辑，可在矢量编辑器内修改；源文件非PSD图层。
- 建议的slider端帽16px为用于测试的参考值，正式应由引擎开发按实现验证。
