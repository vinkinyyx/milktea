- **资产总数**：12个；3个原创母版方向（primary/secondary/icon），9个根据母版派生的状态变体。

- **独立运行图**：`export_png/` 中12个RGBA透明PNG，使用原asset_id命名；**不包含文字、图标、数值等运行态元素**。
- **自动QA**：`qa/asset_qa.json`；包含逐图的尺寸、透明边缘、9切四角像素保真、哈希和透明区域外接框。

## 四状态对应关系

- normal：常规外框+左上柔光，主按钮主色与原规范`#8B4E2F`一致；次按钮和图标按钮为`#F1E2CF`暖奶白。
- pressed：减亮并绘制内凹边缘；按压缩放交给程序完成。
- disabled：降低饱和度但保留可辨边界；**程序必须同步禁止点击**，静态图片不能提供点击逻辑。
- selected：用清晰的**双实线选中边框**额外提示，不依赖单纯变色；动态文字/实际内容由引擎添加。

## 实际核验情况

- 12/12 PNG尺寸与命名符合规格，12/12全画布PNG独立且带透明通道。
- 九切边距均满足非重叠条件；运行尺寸下重新拼接，并验证九切四角与源图像素逐一一致。
- 透明外沿通过，未含文字、图标或伪造平台标识，所有源SVG可再编辑。
- **待游戏实际集成**：触摸目标宽高、disabled不可点击、在375窄屏的视觉/文字对比度、九切与UI布局结合时的表现；静态验收不得冒充完整开发测试。
- 图标按钮仅适用于96×96正方形场景，若变成长条将无法维持圆形视觉，不应滥用九切进行任意长宽比例拉伸。
